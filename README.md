# Random 3 Words

일러스트, 캐릭터, 굿즈, 그래픽 작업을 시작할 때 예상하지 못한 세 단어를 던져 주는 랜덤 키워드 생성기입니다. 완성된 아이디어를 제안하기보다 “이상한데 재미있는” 조합으로 창작의 출발점을 만드는 것을 목표로 합니다.

🔗 [Random 3 Words 바로 사용하기](https://rumod.github.io/random-3-words/)

## 실행 방법

빌드나 설치 과정이 필요하지 않습니다. `index.html`을 브라우저에서 직접 열거나, 프로젝트 폴더에서 간단한 정적 웹 서버를 실행하면 됩니다.

```bash
python3 -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000`으로 접속합니다. 저장소 루트를 GitHub Pages의 배포 대상으로 지정해 바로 게시할 수도 있습니다.

## V1 기능

- 최초 접속 시 무작위 단어 3개 자동 표시
- 전체 목록에서 각 단어를 서로 독립적으로 동일 확률 추첨
- 카테고리 및 동일 단어 중복 허용
- 횟수 제한 없는 `다시 뽑기` 버튼
- 모바일과 데스크톱에 대응하는 반응형 화면
- 559개의 한국어 단어와 향후 확장을 위한 카테고리 정보

## V1 제외 기능

- 개별 단어 다시 뽑기, 단어 개수 선택
- 카테고리 선택 및 표시, 프리셋, 중복 방지
- 저장, 즐겨찾기, 히스토리, 사용자 단어 추가
- 로그인, 테마 및 분위기 필터
